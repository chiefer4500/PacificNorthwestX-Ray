# Pacific Northwest X-Ray (PNWX) Web Catalog

A responsive front-end e-commerce product catalog web application built with HTML5, CSS3, and JavaScript, modeled after Pacific Northwest X-Ray Inc.

## 🚀 Key Features
* **Product Showcase Grid:** Displays popular medical imaging supplies, radiation shielding gear (lead aprons, gloves, glasses, curtains), and quality control testing tools with clean product cards, descriptions, and pricing.
* **Structured Navigation:** Multi-tier category menu for browsing across Accessories, Supplies, Parts, and specialized Equipment sublists.
* **Interactive UI Elements:** Dynamic product expansion using JavaScript to toggle additional catalog items via a "Show More" button, alongside active promotional announcement banners.
* **Professional Layout:** Designed with modern CSS layout techniques (CSS Grid and Flexbox) to ensure a structured, clean interface.

## 🛠️ Tech Stack & Concepts Applied
* **Frontend Languages:** HTML5, CSS3, JavaScript (Vanilla JS).
* **UI/UX Design:** Responsive card-based grid layouts, navigation dropdowns, and custom styling.
* **Asset Management:** Organized local folder architecture for maintaining product images and company branding elements.

## 💻 How to View & Run
1. Clone or download this repository to your computer.
2. Open the **`index.html`** file directly in any modern web browser (Google Chrome, Firefox, Edge, etc.).
3. **Live Hosting:** Enable GitHub Pages under your repository settings (`Settings -> Pages -> Branch: main`) to instantly generate a public URL for your live website!
